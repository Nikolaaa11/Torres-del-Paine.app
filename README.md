# Torres del Paine - Planning Assistant

🏔️ La aplicación definitiva para planificar tu aventura en Torres del Paine

## 🌟 Características

- **Mapa Interactivo del Circuito O**: Visualiza los 8 días del trekking más épico de Patagonia
- **Planificación Paso a Paso**: Guía completa desde 6 meses antes hasta el día del viaje
- **Lista de Equipamiento**: Checklist detallada de todo lo que necesitas
- **Calculadora de Presupuesto**: Compara opciones mochilero, estándar y premium
- **Menú Diario**: Planificación nutricional para cada etapa
- **Modo Offline**: Funciona sin conexión como PWA
- **Optimizado para Móviles**: Diseño responsive para todos los dispositivos

## 📱 Instalación

### Opción 1: PWA (Progressive Web App)
1. Visita [https://nikolaaa11.github.io/Torres-del-Paine.app/](https://nikolaaa11.github.io/Torres-del-Paine.app/)
2. Toca el banner "Instalar" o menú → "Agregar a pantalla de inicio"
3. ¡Listo! Funciona offline como una app nativa

### Opción 2: Servidor Local
```bash
python3 -m http.server 8000
# Abre http://localhost:8000
```

## 🚀 Tecnologías

- React 18 (sin build tools)
- Tailwind CSS (CDN)
- Lucide React Icons
- Service Worker para offline
- PWA con manifest.json

## 📊 Información del Circuito

- **Distancia Total**: 130 km
- **Duración**: 8 días
- **Horas de Caminata**: 60-70 horas
- **Punto Más Alto**: 1,241m (Paso Gardner)
